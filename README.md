# Internship E-Portfolio | Egemen Alkan

Welcome to the source code repository for my E-Portfolio. This application is a single-page React application developed to document my skills, experiences, and the realization of my internship as part of the Bachelor Applied Computer Science program at Thomas More.

The live portfolio is hosted here: [https://egealkan.github.io/](https://egealkan.github.io/)

## 📋 About This Project

This portfolio is designed to present my professional identity to IT professionals and future employers. It adheres to the specific requirements of the E-Portfolio course and serves as the central hub for my internship deliverables.

**Internship Focus:**
* **Company:** Estée Lauder
* **Project Title:** Transforming Production Planning Through Data Intelligence
* **Deliverables:** Enhanced Weekly Planning Report (Power BI) & AI Planning Assistant (Microsoft Copilot Studio).

## 🛠️ Technologies Used

This project is built using the concepts covered in the .NET & React course, utilizing a modern frontend stack:

* **Framework:** [React](https://react.dev/) (v19)
* **Build Tool:** [Vite](https://vitejs.dev/) - Chosen for its fast HMR and optimized build process.
* **Routing:** [React Router](https://reactrouter.com/) (v7) - Handles client-side navigation between portfolio sections.
* **Styling:** CSS Modules / Custom CSS variables for a consistent, terminal-inspired theme.
* **Deployment:** GitHub Pages (via `gh-pages`).

## 📂 Portfolio Structure

The application is structured to cover the following key areas required for the defense:

* **Home:** Introduction and welcome page.
* **About:** Professional profile and background.
* **Internship:** Detailed breakdown of the internship project at Estée Lauder, including the Realisation, Reflection, and Summary documents.
* **Projects:** Showcase of academic and personal IT projects.
* **Experience & Skills:** Overview of technical competencies and work history.
* **Education:** Academic background and course specifics.

## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites
* Node.js (LTS version recommended)
* npm

### Installation

1.  Clone the repository:
    ```bash
    git clone [https://github.com/egealkan/egealkan.github.io.git](https://github.com/egealkan/egealkan.github.io.git)
    cd egealkan.github.io
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Start the development server:
    ```bash
    npm run dev
    ```

4.  Open your browser and navigate to the URL shown in the terminal (usually `http://localhost:5173`).

## 📦 Building and Deployment

The project is configured to deploy directly to GitHub Pages.

To create a production build:
```bash
npm run build
```
To deploy to GitHub Pages (triggers the gh-pages script):
```bash
npm run deploy
```
📝 Linting
ESLint is configured to ensure code quality and consistency.
```bash
npm run lint
```
